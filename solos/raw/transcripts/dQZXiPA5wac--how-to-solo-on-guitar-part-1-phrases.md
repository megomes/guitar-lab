This is Part One of my series on How to Solo on Guitar.

We start with how to make phrases: the foundation of a good guitar solo. Interesting phrases tend to have something quirky going on.

Then we move on to how to arrange phrases in sets - like ABAC - and how easy it is to create a lot of material from just one phrase.

From there we talk about how to morph an A phrase into a B phrase - by using a list of concepts - CHANGE, ADD, SUBTRACT, FLIP, RELOCATE

Then we talk about two ways to practice - one way is to commit to a set - like ABAC or AABC for example - and try to come up with a new A phrase every time.
